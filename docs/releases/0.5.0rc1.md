# Boundary Lab 0.5.0rc1

This release candidate adds an Apple Silicon source workflow for the explicitly
selected BEAT Engine Metal backend. Boundary Lab pins the published Veeesop BEAT
Engine 0.4.0rc1 wheel and rejects unsupported engine versions.

## Metal support and tested scope

On an Apple M5 Max with macOS 26.6.2, Python 3.11.16, and Julia 1.12.7, the
published engine wheel passed Metal instantiate and doctor checks. Boundary Lab
completed these explicit Metal source solves with finite complex results and
`beat_metal` provenance:

- Exterior BEM: `tests/fixtures/remote-exterior.blab.json`, 500 Hz, no symmetry.
- Coupled FEM-BEM: `examples/SKRAM/SKRAM.blab.json`, 80 Hz, X symmetry.

These single-frequency checks qualify only the listed projects and configurations;
they do not establish general numerical parity or support for every mesh,
frequency, symmetry mode, or physical-system model. Although the installed BEAT
catalog advertises an interior FEM Metal solve kind, Boundary Lab has not
hardware-qualified an interior-only project. CUDA hardware qualification and a
packaged macOS application are also outside this release candidate's scope.

BEAT CPU remains the GUI preference default. Metal must be selected explicitly;
an unavailable Metal worker reports an error and does not fall back silently.
Windows/Linux CUDA and ROCm selection behavior is unchanged. Headless automatic
selection remains CUDA-then-CPU.

On macOS, the bundled Ath geometry generator runs `ath.exe` through Wine. Users
can alternatively import Gmsh meshes, including meshes exported with Fusion2Msh
on a supported Fusion host. See [Installation and Setup](../Installation%20and%20Setup.md#macos-apple-silicon)
for the source workflow and exact test scope.

## Qualification

The release PR validation includes the full Python test suite, Ruff lint and
format checks, and an installed-wheel CPU engine integration check. Real Metal
qualification was performed on the M5 Max listed above. Hosted CI cannot execute
Metal GPU kernels; this release candidate does not claim hosted Metal hardware
qualification.
